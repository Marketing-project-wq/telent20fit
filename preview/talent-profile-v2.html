Apa yang diubah

2. Profile strength: persen per bagian kini tampil konsisten di semua ukuran (dulu iPad tegak/Android menghilangkannya).
3. State baru: ditambah tampilan profil kosong (bio/sertifikat/riwayat kosong, strength 30%) dan overflow 7 kategori → "+4".
4. CTA "Lihat Event / Browse events": kini tombol merah di desktop & mobile (dulu di laptop cuma tautan teks).
5. Keterbacaan: teks sekunder di header hitam dinaikkan kontrasnya (rgba .78/.55) & ukuran minimum ~11px.
6. Safe-area: frame HP diberi dynamic island + padding nav bawah env(safe-area-inset-bottom).
7. Chip "+N": jadi lebih jelas & bisa diketuk (min 44px), diuji sampai 7 kategori.
8. ID/EN: disandingkan untuk tombol, label statistik, nama kategori, dan nav — semua muat/ melipat rapi.
9. Data pribadi: tetap kartu sendiri berlabel + masking + catatan privasi (dipertahankan, dirapikan jaraknya).
Tidak diubah (sudah bagus): bahasa visual hitam/putih/merah, layout desktop, kartu sertifikat + badge, ring profile strength, masking privasi, varian Android.
